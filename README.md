# ARA_AURUM — Rilis Resmi ARA PRO GOLD

Repo ini adalah **kanal distribusi rilis** aplikasi desktop **ARA PRO GOLD**
(Architectural Realism Accelerator) — generator prompt realisme arsitektur +
pipeline anti-halusinasi.

- Unduh installer terbaru di tab **Releases**.
- `ARA-PRO-GOLD-Setup-Vx.y.z.exe` — installer Windows (NSIS, auto-update).
- `ARA-PRO-GOLD-Portable-Vx.y.z.exe` — edisi portable (tanpa auto-update).
- `latest.yml` + `.blockmap` — berkas teknis auto-updater, jangan dihapus.

Kode sumber dikelola di repositori terpisah (privat).
